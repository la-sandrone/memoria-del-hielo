## 四、发现 1：空手而归 **100% 由 `fulltext_only` 造成**

- 17 条返回空结果 → **全部**是调用方显式传了 `fulltext_only=true`
  （21 次 ft-only 调用里 17 次空手，**81%**）
- 而且空手的查询里，题材**明明在库**的比比皆是：
  `望远镜 分辨本领 瑞利判据 衍射极限 集光力`（光学系列 66 本）、
  `克尔度规 零测地线 Carter 常数`（微分几何）、
  `魔鬼出没的世界 萨根 怀疑 科学`（卡尔萨根 6 本）
- 机制：`fulltext_only` 走 jieba 分词 + `MATCH ... BOOLEAN MODE`，对**短术语**（`像差`、`寄生`）
  与**长术语串**（8 词英文）命中率极低

**推论**：① 用"结果为空"推断"库里没有"是**错的**；
② **已修（2026-09-21）**：`fulltext_only` / `vector_only` 无命中时**自动补另一路**，
并在返回的 `search_meta.fallback` 里标注（`{"to": "vector_only", "reason": "全文路无命中", "returned_after": N}`）——
调用方不再面对"静默空手"，能区分「原路打不中」与「库里没有」（后者表现为
`results=[] 且 fallback=null`）。

该案例实测：`瑞利判据` + `--fulltext-only` 原来 **0 条** → 现在 **2 条**，
首条正是《几何光学 像差 光学设计（第四版）》的「第 16 章 > 16.2 瑞利判断」。

## 五、发现 2：书级信号能排序，**不能**判"库里有没有"

标定集：正类 **104 条**真实查询（查询时带的 tag 确实存在于库 → 题材确定在库）；
负类 **10 条**确定不在库的构造查询（法式甜点 / 自行车链条 / Nginx / K8s…）。

| 信号 | AUROC（正 = 题材在库） |
|---|---|
| `top1 距离`（幅值） | **0.859** |
| `gap`（d5 − d1） | 0.687 |
| `z`（top1 相对全库距离分布的标准落差） | 0.542 |

排序够用，但**阈值一上就崩**：

| 阈值 | 判"没有"命中 | **误伤在库查询** |
|---|---|---|
| 0.49 | 9/10 | **28/104（27%）** |
| 0.53 | 4/10 | 11/104（11%） |

根因：**书目卡片 = 书名 + 目录**，对**细节型/术语型查询**天然不敏感（真实查询大量是这种），
哪怕题材就在库里。→ 结论：`find_books` **只排序、只回数字，不做存在性判定**
（见 `src/core/search.py` 中 `SearchEngine.find_books` 的 docstring）。

## 六、发现 3：文献推荐的 Score Gap 在我们这里**更差**

- 文献：arXiv [2609.15578](https://arxiv.org/abs/2609.15578)《The Magnitude Mirage》(2026-09)
  主张**弃用原始相似度幅值**、改用**分数分布信号**（Score Gap `s₁−s_k`、LSMV），
  在其场景（**chunk 级 + 逻辑/时序推理**查询，BRIGHT/TEMPO 基准）弃答 AUROC 提升最多 **0.16**。
  相关：RGB benchmark 把「negative rejection（该拒答时拒答）」列为标准能力项。
- 我们这里**正好相反**：幅值 0.859 > gap 0.687 > z 0.542。

差异来源：① 我们是**书级**（书名+目录），他们是 **chunk 级**（正文）；
② 我们的查询以**主题型**为主，不是推理型。→ **文献结论不能跨场景照搬，必须在自己的库上标定。**

## 七、这份台账怎么用

1. **召回回归**：每次改检索（SQL 形状 / 权重 / 分词 / tag 语义）后跑一遍
   `diag_query_corpus.py --stats`，看"空手而归"是否变多。
   **当前基线：17/191，且 100% 是 ft-only 调用**。
2. **阈值标定底座**：`--calib` 直接复算 AUROC 与误伤率；将来若做"chunk 级 + reranker"的存在性判据，
   用同一套正类/负类对比才有可比性。
3. **查询形态参考**：设计 MCP/CLI 工具的参数描述与 docstring 时，按 §二的真实形态写引导语。
